# 🔋 Coverage Pulse
> **Proactive Insurance Health & Wealth Intelligence Platform**  
> *นวัตกรรมระบบวิเคราะห์ชีพจรความคุ้มครองอัจฉริยะ พลิกโฉมการดูแลประกันภัยจาก "เชิงรับ" สู่ "เชิงรุก"*

## 📌 บทนำและปัญหาที่ระบบต้องการแก้ไข (Problem Statement)

ปัญหาหลักในอุตสาหกรรมประกันภัยคือ **"ประกันหมดความหมายเร็วกว่าหมดสัญญา"** 
เนื่องจากบริบทชีวิตของผู้เอาประกันเปลี่ยนแปลงตลอดเวลา เช่น แต่งงาน, ย้ายงาน, มีบุตร, หรือเริ่มมีความเสี่ยงด้านสุขภาพ แต่ระบบประกันแบบดั้งเดิมถูกออกแบบมาให้ทบทวนความคุ้มครองเพียงปีละครั้งเมื่อถึงรอบต่ออายุ ส่งผลให้เกิด **"ช่องโหว่ความคุ้มครอง"**  ที่ไม่สอดคล้องกับความเสี่ยงจริงในปัจจุบัน

### ผลกระทบต่อกลุ่มเป้าหมาย
1. **ลูกค้า (Customers):** ถือกรมธรรม์ที่ไม่คุ้มครองความเสี่ยงใหม่ๆ ขาดเครื่องมือช่วยทำความเข้าใจสถานะความคุ้มครองของตนเองแบบ Real-Time และรู้สึกว่าประกันเข้าถึงยาก
2. **นายหน้าประกัน (Brokers):** ทำงานเชิงรับ (Reactive) และสูญเสียโอกาส เพราะต้องพึ่งพาการสุ่มโทรหรือรายชื่อใกล้หมดอายุ (Cold Call) ขาดสัญญาณเตือนเหตุการณ์ชีวิต (Life-event trigger) ทำให้การติดต่อมักกลายเป็นการยัดเยียด

### Solution "Coverage Pulse"
**Coverage Pulse** แปลงข้อมูลความคุ้มครองที่ซับซ้อนให้เข้าใจง่ายในรูป **"สถานะแบตเตอรี่ (Battery Health 0-100%)"** 3 สี (เขียว-เหลือง-แดง) พร้อมสมองกล **Relevance Engine** และ **Agentic AI** ที่ช่วยวิเคราะห์และส่งสัญญาณแจ้งเตือนทั้งฝั่งลูกค้าและตัวแทนอย่างแม่นยำ ถูกคน ถูกจังหวะเวลา โดยเคารพกฎหมาย PDPA อย่างเคร่งครัด

## 🌟 จุดเด่นและนวัตกรรมหลัก (Key Innovations)

1. **Relevance Engine:** สมองกลรวบรวมสัญญาณจาก 4 แหล่ง (ธุรกรรม/KYC, การอัปเดตของลูกค้า, Hospital Touchpoint ผ่าน Double Opt-in และ Broker Verification) คำนวณคะแนนแบบถ่วงน้ำหนักตามระดับความน่าเชื่อถือ
2. **Pre-call Brief & Next-Best-Action (NBA):** สร้างสรุปประวัติ เหตุผลที่ต้องติดต่อ ไทม์ไลน์ และสคริปต์การโทรเฉพาะบุคคลด้วย AI ช่วยลดเวลาเตรียมตัวของตัวแทนจาก **15 นาที เหลือเพียง 1 นาที**
3. **Customer Sandbox (Gamified Empowerment):** พื้นที่ให้ลูกค้าจำลองทดลองเติมสัญญาเพิ่มเติมด้วยตนเองเพื่อดูแบตเตอรี่ฟื้นฟูกลับมาเต็ม 100% และกดส่ง **Warm Lead** หาตัวแทนได้ทันที
4. **2-Tier Assessment Form:** ระบบคัดกรองความต้องการแบบ 2 ชั้นสำหรับลูกค้าใหม่ (Cold-start) ตอบโจทย์หมวดประกัน 8 ประเภทของกรุงศรี โดยไม่ก้าวล่วงข้อมูลสุขภาพเชิงลึก
5. **PDPA Consent Center:** ศูนย์จัดการความยินยอมที่ลูกค้าเปิด-ปิดแหล่งสัญญาณได้อิสระ พร้อมบันทึก **Immutable Audit Trail** ย้อนหลังระดับวินาที

## 🚀 วิธีการติดตั้งและเริ่มใช้งาน (Getting Started)

### ข้อกำหนดเบื้องต้น (Prerequisites)
* **Node.js:** เวอร์ชั่น 18.0.0 ขึ้นไป (รองรับ Built-in `node:sqlite`)
* **Web Browser:** Google Chrome, Microsoft Edge, Firefox, Safari

### ขั้นตอนการติดตั้ง
1. **Clone repository หรือดาวน์โหลดโฟลเดอร์โครงการ:**
   ```bash
   git clone https://github.com/ATOMPassakorn/Coverage-Pulse
   cd stitch_ai_insurance_health_battery
   ```

2. **ติดตั้ง Dependencies:**
   ```bash
   npm install
   ```

3. **เริ่มการทำงานของเซิร์ฟเวอร์:**
   ```bash
   npm start
   ```
   *(หรือใช้ `npm run dev` สำหรับโหมด Hot Reload ขณะพัฒนา)*

4. **เปิดเบราว์เซอร์เข้าใช้งานระบบ:**
   * 🌐 **Portal Switcher (หน้าเลือกระบบ):** [http://localhost:3000/](http://localhost:3000/)
   * 👤 **Customer Portal (ฝั่งลูกค้า):** [http://localhost:3000/customer](http://localhost:3000/customer)
   * 💼 **Broker Portal (ฝั่งที่ปรึกษา):** [http://localhost:3000/broker](http://localhost:3000/broker)
   * 📋 **Audit Log (ประวัติความยินยอม):** [http://localhost:3000/broker/audit-log.html](http://localhost:3000/broker/audit-log.html)

### การเชื่อมต่อ Local AI Model (ทางเลือกเพิ่มเติม)
ระบบมีกลไก Intelligent Fallback ในตัว สามารถทำงานได้อย่างสมบูรณ์แบบโดยไม่ต้องเปิด Ollama  
หากต้องการเปิดใช้งานโมเดล AI ในเครื่อง:
1. ติดตั้ง [Ollama](https://ollama.com/)
2. ดึงโมเดลภาษา: `ollama pull qwen2.5:7b`
3. รัน Ollama Service ที่พอร์ตเริ่มต้น (`http://localhost:11434`)
